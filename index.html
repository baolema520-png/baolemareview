App Review Guide

BAOLEMA Secure

A secure browser experience with VPN-gated access, user-defined access keys, alternate browser mode, text highlighting, short links, PDF/QR sharing, and video link handling.

What the app does

BAOLEMA Secure opens its main protected browser only after the device has an active VPN and the network location is allowed. This is one of the app's core security functions.

The app also includes an alternate browser mode so review can test navigation without the VPN-gated route.

Important review setup

On a clean install, the app does not include default keys. Reviewers define two 6-digit keys during first launch.
  • Main secure key: reviewer may choose any 6-digit number.
  • Alternate browser key: please set 123456.
  • Main secure flow requires any active VPN on the review device.

Step-by-step review flow

  1. Install and open BAOLEMA Secure.
  2. When prompted, create two 6-digit keys.
  3. Set the alternate browser key to 123456.
  4. Connect any VPN on the iOS review device.
  5. Enter the main key to test secure verification.
  6. After successful verification, the protected browser opens.
  7. Use 123456 to test the alternate browser mode without the VPN-gated flow.

Features to verify

  • User-defined access keys and key reset flow.
  • VPN-gated secure browser access.
  • Alternate private browser mode.
  • Text selection and highlighting tools.
  • Short link creation from pages or highlighted text.
  • PDF sharing via QR workflow.
  • Video link handling and subtitle tools.
  • Accessible labels on icon-only browser controls.
  • Privacy manifest and polished launch screen.
